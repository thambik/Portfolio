# Kasimala Thambi — Portfolio

A mobile-first React + Vite developer portfolio inspired by the cinematic feel of the supplied Netflix portfolio, but redesigned with an original recruiter-focused layout.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Customize

Edit `src/main.jsx` for content, links and projects. Edit `src/styles.css` for the visual theme.

## Deploy

Import this folder into Vercel or Netlify. The build command is `npm run build` and the output directory is `dist`.
